# 追加プロンプトのプリセット例

Yui Agent には **追加プロンプト** という仕組みがあり、結衣の基本人格 (= `yui-prompt.ts`、触れません) の末尾に **ご主人様が指定した追加指示** を append して、結衣の応答トーンや態度を切り替えられます。

このディレクトリは、すぐ使える設定例を `.txt` で並べたものです。気に入ったものを **設定 > 秘書 > 追加プロンプト** にコピー&ペーストして登録してください。

---

## 使い方

1. Yui を起動して、ご主人様アカウントでログイン
2. 画面右上の **設定 (歯車アイコン) → 秘書タブ → 追加プロンプト** を開く
3. 「**+ 新規プリセット**」をクリック
4. ラベル (例: `寄り添いモード`) と本文 (= 下の `.txt` から丸ごとコピペ) を入れて保存
5. 一覧から「**有効化**」を押すと、結衣が次のターンからそのモードで応答する
6. 「**なし**」に戻すと基本人格だけになる

複数のプリセットを登録しておいて、状況や気分で切り替えるのが想定運用です。

---

## 同梱しているプリセット

| ファイル | 用途 |
|---|---|
| [`companion-mode.txt`](companion-mode.txt) | **寄り添いモード** — 業務はきっちりこなしつつ、温かく落ち着いた距離感で対応 (= 標準的なデフォルト感) |
| [`spartan-mode.txt`](spartan-mode.txt) | **スパルタモード** — 寄り添いより指摘を優先、客観的・直球な姿勢でご主人様の成長を促す |

---

## カスタマイズの作り方

`.txt` の中身を参考に、ご主人様自身のモードを作るのも歓迎です。よく使う構造は:

```
このモードは ○○ のための姿勢です。

## 口調 / トーン
- 〜

## 応答スタイル
- 〜

## 期待される追加挙動
- 〜

## 避ける表現
- 〜
```

注意点:
- 結衣の基本人格 (= 「ご主人様」呼び、結衣の名前、敬語ベース等) は `yui-prompt.ts` で保証されているので、追加プロンプト側で重複して書く必要はない
- 追加プロンプトで「ご主人様」を「あなた」に変える等の指示はできるが、基本人格との衝突は強く効くプロンプト側が勝つ (= モード次第で base がずれる)
- 長すぎる本文は token を消費するので、必要最小限の差分指示に絞ると軽い
